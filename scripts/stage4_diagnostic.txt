# WHAT TO LOOK FOR in crr_channels:
#
#  (a) a vector of 63 integers in 1..64  -> THIS IS THE ANSWER.
#      It lists which physical electrodes were retained. Full alignment
#      for all 24 subjects becomes possible.
#
#  (b) a vector of 1 integer (or a few)  -> these are the EXCLUDED channels.
#      Also usable: retained = setdiff(1:64, crr_channels).
#
#  (c) a cell array of channel NAME strings ('Fp1','Fz',...) -> even better,
#      gives explicit electrode labels.
#
#  (d) empty / a scalar like 63          -> no identity info. Fall back to
#      the 15 subjects with the complete 64-channel montage.
